# Documentation index

One topic per page. Every page starts with who it is for. Commands in the quickstart are executed by `scripts/docs-check.sh`.

- [quickstart.md](quickstart.md) - for new operators: the ten-minute path to `tuishou status` proof.
- [install.md](install.md) - for operators installing or upgrading the shell installer by hand.
- [configuration.md](configuration.md) - reference for every `tuishou.toml` key, default and example.
- [operations.md](operations.md) - for operators running updates, rollbacks and health checks.
- [security.md](security.md) - for reviewers: verification scope, trust boundaries and reporting.
- [limits.md](limits.md) - for planners: supported platforms and non-goals.
- [troubleshooting.md](troubleshooting.md) - for on-call users: exact messages and fixes.
- [cli.md](cli.md) - for script authors: commands, flags, environment and exit codes.
- [architecture.md](architecture.md) - for contributors: data flow and state locations.
- [CHANGELOG.md](../CHANGELOG.md) - release notes and upgrade requirements.

Earlier topic pages remain available: [components](components.md), [install and update](install-update.md), [node update](node-update.md), [verify a release](verify-release.md), [auto-update](auto-update.md), [dogfooding](dogfooding.md) and [FAQ](faq.md).
